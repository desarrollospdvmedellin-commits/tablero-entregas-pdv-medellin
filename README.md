# Tablero de Entregas PDV Medellín

Aplicación web para la gestión de entregas de motocicletas Yamaha.

## Funcionalidades

- Tablero en tiempo real
- Agenda de citas
- Carga de base diaria desde Excel
- Historial de entregas
- Exportación a Excel
- Impresión de agenda
- Seguimiento de tiempos de espera

## Tecnologías

- HTML5
- CSS3
- JavaScript
- SheetJS (XLSX)
